## About Me

Computer Engineering student building full-stack applications, containerizing them with Docker, and shipping through automated CI/CD pipelines. Currently going deep on cloud-native patterns, Kubernetes, and infrastructure as code with Terraform.

- **Docker & Containers** — bridge networking, multi-container setups, Nginx reverse proxy, Redis caching, DockerHub publishing
- **CI/CD** — GitHub Actions pipelines with changelog automation via Conventional Commits
- **Infrastructure as Code** — Terraform, HCL, cloud-native deployment patterns
- **AWS** — hands-on with EC2, S3, Lambda; currently pursuing cloud-native architecture patterns
- **Full Stack (MERN + Go)** — REST APIs, real-time apps with WebSockets, auth flows, Go + Gin backends
